Tablero Responsivo - Escalado Perfecto para Múltiples Resoluciones

📺 2K (2560×1440)

max-width: 1800px
El tablero escala hasta 1800px manteniendo aspect ratio 15:11. Perfecto para monitores grandes.

💻 1080p (1920×1080)

max-width: 1400px
Optimizado para Full HD. El tablero ocupa el 73% del ancho con márgenes cómodos.

📓 Portátil (1366×768)

max-width: 1000px
Resolución más común en portátiles. El tablero es legible sin scroll horizontal.

📱 Móvil (320-767px)

max-width: 100vw
Ocupa el 100% del viewport. Padding reducido para maximizar espacio.

🎯 Leyenda del Tablero

Equipo Superior (defiende P1)
Equipo Inferior (defiende P2)
Balón (posición inicial: 7-6)
Líneas de área (amarillas)
Córners (puntos amarillos)

🔧 Cómo Usar en tu Proyecto

1. Importar SVG:
<img src="assets/tablero.svg" class="tablero-svg">

2. O inline para animaciones:
<svg viewBox="0 0 165 110" ...>

3. CSS clave:
width: 100%; max-width: min(90vw, 90vh * 1.36);

✨ Ventajas de este Enfoque

✅ SVG vectorial: Escala infinitamente sin pixelarse
✅ ViewBox: Mantiene proporciones automáticamente
✅ Unidades relativas: % y viewBox, no píxeles fijos
✅ CSS clamp(): Tipografía responsive
✅ Aspect ratio: 15:11 siempre preservado
