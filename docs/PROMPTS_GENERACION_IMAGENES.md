## 🔧 PARÁMETROS RECOMENDADOS

### Midjourney v6

| Parámetro | Valor | Uso |
|-----------|-------|-----|
| `--ar` | `4:3`, `16:9`, `1:1` | Aspect ratio según uso |
| `--v 6.0` | `6.0` | Versión más reciente |
| `--stylize` | `100-600` | Más alto = más artístico |
| `--niji 6` | `6` | Para estilo anime/illustración |

### DALL-E 3

- Usar prompts más descriptivos y naturales
- Especificar "flat design" o "3D render" claramente
- Incluir contexto de uso (web, móvil, print)

### Stable Diffusion XL

- Añadir `masterpiece, best quality, high resolution` al inicio
- Usar negative prompts: `blurry, low quality, distorted`
- CFG scale: 7-9 para seguir bien el prompt

## 💡 CONSEJOS PARA MEJORES RESULTADOS

### 1. **Sé Específico con el Aspect Ratio**
```
✅ --ar 16:9 (para web banners)
✅ --ar 1:1 (para iconos)
❌ Sin especificar (resultado inconsistente)
```

### 2. **Define el Estilo Claramente**
```
✅ "flat vector design, minimal style"
✅ "3D render, studio lighting, product photography"
❌ "nice looking game" (muy vago)
```

### 3. **Especifica el Uso**
```
✅ "mobile game UI assets"
✅ "GitHub repository banner"
✅ "Instagram post, square format"
```

### 4. **Itera sobre Resultados**
- Genera 4-8 variaciones
- Selecciona la mejor
- Usa `V1`, `V2`, `V3`, `V4` en Midjourney
- Ajusta prompt basado en resultados

### 5. **Consistencia de Estilo**
Para mantener consistencia entre assets:
- Usa las mismas palabras clave
- Mantén los mismos parámetros
- Genera todo en una misma sesión

## 📁 FLUJO DE TRABAJO RECOMENDADO

### Fase 1: Tablero Base
1. Generar tablero top-down con prompt base
2. Probar variaciones de color (verde más claro/oscuro)
3. Seleccionar mejor resultado
4. Upscale a máxima resolución

### Fase 2: Fichas
1. Generar set de fichas aisladas
2. Crear variaciones (diferentes ángulos)
3. Exportar como PNG con fondo transparente

### Fase 3: Marketing
1. Usar tablero y fichas aprobadas
2. Generar composiciones para redes
3. Crear versiones con y sin texto

### Fase 4: UI Assets
1. Iconos de acciones
2. Botones y controles
3. Fondos y loading screens
