MasterGoal · Ajuste del campo en móvil

Simulación de un móvil (proporción ~1:2). Izquierda = como está hoy (ajuste por altura, sobran laterales). Derecha = propuesta: el campo llena el ancho, margen mínimo para no cortar porterías.

Qué cambia: hoy el SVG usa height: calc(100vh - HUD); width:auto → al ser el tablero alto, se ajusta por altura y deja banda verde a los lados. La propuesta usa width:100vw; height:auto con un viewBox que recorta casi todo el margen lateral, dejando solo un colchón arriba/abajo para las redes de portería.

El motor no cambia: mismas coordenadas lógicas, solo cómo se encuadra el SVG.
